# opencitieslab/.github

Organisation-wide files for [Open Cities Lab](https://www.opencitieslab.org/) on GitHub.

| Path | Purpose |
|---|---|
| [`profile/README.md`](profile/README.md) | The public profile shown at [github.com/opencitieslab](https://github.com/opencitieslab) |
| [`assets/`](assets/) | Banner and logomarks used by the profile |
| `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SECURITY.md`, `SUPPORT.md` | Default community health files, used by any `opencitieslab` repo that doesn't have its own |
| `ISSUE_TEMPLATE/`, `PULL_REQUEST_TEMPLATE.md` | Default issue and PR templates |

Brand colours (from the OCL logomark): `#FAAD00` (O), `#D66139` (C), `#2F3542` (L). Supporting colours: `#6EDABB`, `#4D9E4D`, `#0984E3` and `#837DD1`.

> These defaults apply only to repositories in the `opencitieslab` org. Repositories under [`opendatadurban`](https://github.com/opendatadurban) need their own copy of these files, or an `opendatadurban/.github` repo.
